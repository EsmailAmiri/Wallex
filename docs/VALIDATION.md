# نتیجه بررسی نسخه اولیه

## اتصال رسمی والکس — وضعیت جاری

پس از ارائه آدرس‌ها توسط کاربر، صفحه رسمی `https://wallex.ir/landing/mcp/#steps` دریافت و تنظیم Streamable HTTP با هدر X-API-Key تأیید شد. اتصال مستقیم به `https://api.wallex.ir/mcp` سرور `api.wallex.ir` نسخه `1.0.0` و ۵۲ ابزار را معرفی کرد. دریافت کندل و خواندن موجودی با کلید فعلی از ابزارهای رسمی موفق بود. پنل و منبع ایجنت اکنون از همین نشست رسمی استفاده می‌کنند؛ توضیحات پل محلی پایین این سند، تاریخچه نسخه قبلی‌اند.

فقط ابزارهای خواندنی بازار، کندل، موجودی و کارمزد در کلاینت مجازند. ابزارهای مالی و تغییر وضعیت کشف‌شده قابل فراخوانی نیستند. قواعد ۳۴۵ بازار، اعتبار ثابت و مهلت هکاتون حفظ شدند. ۲۹ آزمون Python شامل نگاشت schema رسمی، مقصد محدود هدر کلید، فیلتر بازار و منع ابزارهای مالی موفق بودند.

## قواعد اجباری طرح

مجموعه کامل پس از اعمال این قواعد: ۲۳ آزمون Python موفق. بررسی مهلت در حلقه واقعی سرور با ساعت شبیه‌سازی‌شده و بدون دریافت داده تازه هم پاس شد. این بررسی یک اتصال SQLite بسته‌نشده را آشکار کرد؛ چرخه اتصال با بستن قطعی در پایان هر تراکنش اصلاح و آزمون دوباره موفق شد.

قواعد اصلی در `AGENTS.md` و `docs/CHALLENGE_RULES.md` ثبت و در موتور، سرور و MCP اعمال شدند. فهرست ارائه‌شده کاربر شامل ۳۴۵ بازار است. هر یک از این نمادها در آزمون مستقیم مرز اجرای معامله رد شد؛ شکل‌های اسلش‌دار، فشرده و با حروف کوچک نیز آزموده شدند. تلاش برای تغییر اصل اعتبار یا تزریق تنظیم خاموش‌کردن قواعد و زمان انقضا رد می‌شود.

تبدیل تاریخ دقیق شروع ۱۴۰۵/۰۷/۲۹ ۲۰:۳۲ و پایان ۱۴۰۵/۰۸/۰۲ ۲۰:۳۲ به زمان تهران بررسی شد؛ اختلاف دقیقاً ۲۵۹۲۰۰ ثانیه است. بازنشانی جلسه deadline را تغییر نمی‌دهد. بک‌تست به ۷۲ ساعت محدود و به تومان تسویه می‌شود. توقف اجرای سایه در انقضا بدون دریافت کندل جدید نیز آزموده شده است.

آزمون مرورگر صفحه قواعد، شمارش ۳۴۵ نماد، جست‌وجوی نمادهای ویژه، غیرقابل ویرایش بودن سرمایه، رد تغییر اصل اعتبار از API، حفظ deadline و عرض موبایل موفق بود. اتصال MCP و احراز هویت موجودی پس از راه‌اندازی نسخه جدید دوباره تأیید شدند. اجرای واقعی مالی همچنان وجود ندارد.

## اتصال MCP اضافه‌شده

- ۱۴ آزمون Python موفق؛ آزمون‌های تازه عبور ورودی ایجنت از MCP، رد بازه یا نماد نامنطبق، رفتار بدون کلید، مقصد ثابت کلید، پاک‌سازی خطای احراز هویت و مسدود بودن ابزار مالی را بررسی می‌کنند.
- نشست واقعی MCP شامل initialize، tools/list و tools/call روی پل stdio محلی برقرار شد؛ هفت ابزار کشف شدند و داده واقعی والکس از ابزار کندل دریافت شد.
- پس از تنظیم محلی کلید توسط کاربر، درخواست خواندن موجودی موفق شد. محتوای موجودی یا کلید در گزارش آزمون ثبت نشده است. این موفقیت نوع حساب اعتباری یا عضویت در چالش را اثبات نمی‌کند.
- منبع فعال جلسه `wallex_mcp` و حالت shadow است؛ خود ایجنت در حالت توقف باقی مانده و هیچ سفارش واقعی ارسال نشده است.
- آزمون مرورگر صفحه اتصال، نمایش تأیید بازار و حساب، انتخاب منبع MCP، انتقال از پورت قدیمی به ۸۷۶۶ و عرض موبایل موفق بود؛ خطای JavaScript مشاهده نشد.
- بررسی شد که کلید واقعی در خروجی JSON یا فایل جاوااسکریپت مرورگر وجود ندارد و `.env` در Git نادیده گرفته می‌شود.
- این اتصال یک پل پروژه روی API رسمی است؛ سرور MCP رسمی میزبانی‌شده یا سرویس ایجنت والکس در این اجرا معرفی یا تأیید نشده است.

- ۹ آزمون Python موفق: حسابداری، سقف سرمایه، عدم نگاه به آینده، زمان اجرای سیگنال، ماندگاری خروج ریسک، توقف افت، اعتبار OHLC و زمان‌ها، حذف کندل باز و تجمیع بازه نامنطبق.
- بررسی syntax جاوااسکریپت و compile فایل‌های Python موفق.
- آزمون مرورگر Chromium در اندازه دسکتاپ و موبایل موفق: شروع، توقف، تعویض مدل و الگوریتم، بک‌تست، ذخیره ریسک و خروجی JSON. خطای JavaScript مشاهده نشد؛ در عرض ۳۹۰ پیکسل، overflow افقی صفحه وجود نداشت.
- بررسی تصویری پنل، صفحه نتیجه بک‌تست و نسخه موبایل انجام شد. ایراد نوار ناوبری موبایل اصلاح و دوباره آزمایش شد.
- دریافت واقعی OHLCV والکس موفق؛ سرویس عملاً کندل یک‌دقیقه‌ای بازگرداند. تشخیص و تجمیع به ۱۵ دقیقه پیاده و آزموده شد.
- بازاجرای گزارش ذخیره‌شده، شاخص‌ها و معاملات یکسان تولید کرد.

## خروجی پژوهشی اولیه

با تنظیمات پیش‌فرض، بذر ۴۲ و ۴۸۰ کندل ساختگی، ۵ معامله رفت‌وبرگشت، بازدهی خالص حدود ۱٫۷۷٪ و افت سرمایه حدود ۰٫۴۶٪ به دست آمد. **این نتیجه، عملکرد واقعی بازار نیست.**

در پنجره ۴۸۰ کندلی واقعی BTC/TMN که هنگام توسعه دریافت شد، همان تنظیمات پیش‌فرض ۸ معامله رفت‌وبرگشت، بازدهی حدود **منفی ۰٫۸۸٪** و افت حدود ۱٫۱۲٪ داشتند. نتیجه زیان‌ده همان‌طور که محاسبه شد نگهداری شده است. هزینه‌های این آزمون فرض تنظیم‌شده موتور هستند، نه سطح کارمزد تأییدشده حساب خاص.

گزارش‌های کامل ورودی و خروجی در زمان توسعه در `artifacts/demo-evaluation.json` و `artifacts/wallex-evaluation.json` تولید شدند. برای ارزیابی تازه از `backtest.py` استفاده کنید. استراتژی برای سودآوری اعتبارسنجی نشده و هیچ معامله واقعی برای این بررسی ارسال نشده است.
